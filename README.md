# ✦ Dovahkiin Astral (Gemini Minimal Edition)

Нативное Android-приложение (Android 13/14+, SDK 33-34) для отслеживания привычек в эстетике **Google Gemini** с механикой созвездий **Skyrim**.

### Что внутри архива:
- **Постоянное сохранение (SQLite)**: все уровни навыков, выполненные дни, серии и созданные привычки автоматически сохраняются в базу `dovah_astral_v2.db` на телефоне.
- **Эстетика Google Gemini**: глубокий темный фон (`#0E1015`), плавающие навигационные пилюли, мягкие астральные градиенты (`Gemini Blue` и `Gemini Purple`), минимум визуального шума.
- **Облачная автосборка APK (`.github/workflows/android.yml`)**: собирает готовый `.apk` прямо на серверах GitHub без необходимости устанавливать Android Studio.
